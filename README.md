# SwiftMap

SwiftMap is a static homepage for the SwiftMap project.

## What’s in this repo

- `docs/index.html` - the GitHub Pages publishing entry point
- `design/` - design goals and implementation notes for the page

## Local Preview

There is no build step. Open `website/index.html` directly in a browser, or serve the `website/`
directory with any static file server.

## Publishing

GitHub Pages can publish from the `main` branch and the `/docs` folder. Select that source in the
repository Settings page. If you use a custom workflow instead, publish the contents of `docs/`.
